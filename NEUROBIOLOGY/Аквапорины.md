# Аквапорины

*Аквапорины* (AQP 0, 1, 2, 4, 5, 6, 8) проницаемы только для воды. *Акваглицеропорины* (AQP 3, 7, 9, 10) имеют более широкую пору и проницаемы также для СО$_2$, аммиака, мочевины. Непроницаемы для заряженных молекул. 

Тетрамеры, каждая субъединица имеет собственную пору и включает 6 трансмембранных сегментов и 2 петли, образующие узкую часть поры в форме песочных часов.

В самом тонком месте (которое по диаметру равно молекуле воды) находится положительно заряженный аргинин, который отталкивает любые катионы. Это обеспечивает селективность.

Есть в почках, отростках астроцитов в ЦНС, в хрусталике, в коже и железах. В ЦНС нужны для продукции ликвора, обмена жидкости и "промывания" тканей. Акваглицеропорины позволяют передавать лактат из астроцитов в нейроны в качестве альтернативного источника энергии.
