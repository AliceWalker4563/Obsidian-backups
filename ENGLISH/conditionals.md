# Zero Conditional

IF  V1,  V1   (general statements | without time at all)

Use to state truth, scientific facts, 100% certain cause-and-effect relationships.

*If a sentient being feels pain, it suffers. If a protein has a chain of ubiquitins attached to it, proteasome decomposes it.*

# First Conditional

IF  V1, will/should/can/might + V   (present condition ---> future result)

Use to describe possible future events, realistic outcomes of actions.

*If you start doing a new thing today, you will see results very soon. If a cat meows at me, i will pet it.*

# Second Conditional

IF  V2, would + V   (present condition ---> future/present result)
to be ---> were

Use to discuss hypothetical, imaginary or unlikely situations in the future or present and their outcomes.

*If i were sorry, it would be a different story. If we engineered crops to perform C4 photosynthesis, we could increase crop yields by 50%.* 

# Third Conditional

IF had + V3, would have + V3    (past condition ---> past result)

Use to describe imaginary event in the past that did not happen (and its possible consequences), to convey regret or relief. 

*If you had bought a silly cat image in 2019, you would have been rich in 2020. If I had been born in another country, I would have become an activist.*

# Mixed Conditionals

### Type I

IF had V3, would + V   (past condition ---> present result)

Use to describe hypothetical event in the past that alter the reality of the present. Regrets as well?

*If humanity had transitioned to renewable energy decades ago, the current situation wouldn't be so bad.*

### Type II

IF  V2, would have + V3   (present condition ---> past result)
to be ---> were

Use to talk about hypothetical present truth or ongoing event that alters an event in the past that already happened. 

*If all humans were altruistic, we would have eradicated poverty decades ago.*



---
There is no comma in reversed order of clauses:
	*if-clause, result-clause*
	*result-clause if-clause*
