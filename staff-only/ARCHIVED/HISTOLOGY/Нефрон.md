# Строение нефрона
![[Drawing 2026-08-21 11.09.00.excalidraw.png|430]]
В зависимости от расположения нефроны бывают:

- *Интракортикальные* (85%) - тельца в наружной коре, петля Генле короткая,
- *Юкстамедуллярные* (15%) - тельца на границе коры и мозгового вещества, петля Генле длинная,
- *Субкапсулярные* - тельца под капсулой почки. 

### Почечное тельце

Почка состоит из *коркового* и *мозгового* вещества. В корковом располагаются *мальпигиевы тельца* - фильтрационный отдел нефрона. Они состоят из двух основных компонентов:

1. *Клубочек* (гломерула) - сеть фенестрированных[^1] капилляров, образованных разветвлениями приносящей артериолы. Эндотелий капилляров представляет собой плоские удлиненные клетки с овальным ядром по центру. Выносящая артериола тоньше приносящей.
2. *Боуменова капсула* - эпителиальная структура из двух листков:
	- Висцеральный (подоциты, прилегает к капиллярам),
	- Париетальный (наружный листок, выстлан эндотелием).

### Извитые канальцы

|                    | Проксимальный извитой каналец                            | Дистальный извитой каналец                       |
| ------------------ | -------------------------------------------------------- | ------------------------------------------------ |
| Эпителий           | Однослойный призматический                               | Однослойный кубический                           |
| Окраска цитоплазмы | Оксифильная (темно-красная), много митохондрий           | Слабо оксифильная (розовая)                      |
| Апикальный полюс   | Щеточная каемка (для увеличения площади реабсорбции)     | Каемки нет                                       |
| Просвет            | Узкий, звездчатый                                        | Широкий                                          |
| Функция            | Реабсорбция 100% глюкозы, аминокислот и 80% воды и ионов | Регулируемая гормонами реабсорбция воды и натрия |

Клетки соединены герметичными *плотными контактами*, у базального полюса наблюдается *базальная исчерченность*. Она представляет собой базальный лабиринт и скопление митохондрий и сильнее выражена там, где идет активный транспорт ионов с затратами АТФ (т.е. в дистальных канальцах).

В месте, где дистальный извитой каналец касается почечного тельца, располагается *плотое пятно* - область плотно упакованных призматических эпителиальных клеток (в микроскоп выглядит темнее). Является частью юкстагломерулярного (эндрокринного) аппарата почки, по сути -  осморецептором, заставляет остальные клетки аппарата синтезировать ренин в ответ на изменение концентрации ионов.

### Петля Генле

Нужна для концентрирования мочи. Противоточный механизм.

| Нисходящее колено (тонкое)                                                  | Восходящее колено (толстое)                                      |
| --------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| Всасывает только воду                                                       | Всасывает только соли, непроницаемо для воды                     |
| За счет большой концентрации солей в мозговом веществе вода уходит пассивно | Активно выкачивает соли в мозговое вещество почки с затратой АТФ |

### Собирательные трубочки

В верхней части эпителий однослойный кубический, в нижней - призматический. В *светлые* клетки АДГ встраивает аквапорины и заставляет активно всасывать воду для концентрирования мочи. *Темные* клетки могут секретировать ионы Н+, аммиак или бикарбонаты для поддержания кислотно-щелочного баланса. 


[^1]: Фенестры - округлые поры 70-100 нм в диаметре, "молекулярное сито"
