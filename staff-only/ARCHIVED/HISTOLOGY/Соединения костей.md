# Соединения костей

- Непрерывные - неподвижное соединение, не имеет полости:
	- *Синдесмозы* - соединение с помощью соединительной ткани (связки, мембраны, швы),
	- *Синхондрозы* - соединение с помощью хряща,
	- *Синостозы* - костные сращения.
- Прерывные - подвижное соединение, имеет полость: 
	- Одноосные: блоковидный, цилиндрический,
	- Двухосные: эллипсовидные, седловидные,
	- Трехосные: шаровидные, плоские.
- Гемиартрозы - переходные формы соединения костей от неподвижных к подвижным.
