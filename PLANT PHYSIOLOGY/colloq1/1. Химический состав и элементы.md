# Химический состав клетки. Макро-, микро- и ультрамикроэлементы, их роль

*Макроэлементы* (>0.01%): **H**, **C**, **O**, **N**, P, Ca, Mg, Na, K, Cl, (Fe).
*Микроэлементы* (0.01-10$^{-5}$%): (Fe), Cu, Mn, Zn, B, F, Co, Ni, Ag, Мо и др.
*Ультрамикроэлементы* (<10$^{-5}$%): Se, Au, Pt, Xe, Ar, Pb, Ra, Cs и др. 

Принцип классификации: относительное содержание элемента в клетке и физиологическая потребность. Про функции в общем можно сказать так: есть структурная и регуляторная. У макроэлементов обычно более выражена *структурная*, у остальных - *регуляторная*.

## Макроэлементы

| Элемент    | Где и зачем                                                            |
| ---------- | ---------------------------------------------------------------------- |
| H, C, O, N | 95% сухой массы клетки, основа Б, Ж, У, Н/К                            |
| Р          | ДНК, РНК, АТФ, фосфолипиды, NAD, NADP                                  |
| К          | Катион, осморегуляция, тургор, открытие устьиц, активация ферментов    |
| Na         | Катион, тургор, САМ и С4 фотосинтез, галофиты выкачивают из почвы воду |
| Cl         | Анион, работа ФСII, тургор, активация протонной помпы тонопласта       |
| Са         | Пектаты кальция в срединной пластинке                                  |
| Мg         | Хлорофилл, активация киназ и Рубиско                                   |
| S          | Цистеин, метионин, третичная структура, витамины В1 и В7, КоА          |

## Микроэлементы

| Элемент | Где и зачем                                                                                                      |
| ------- | ---------------------------------------------------------------------------------------------------------------- |
| Fe      | Цитохром, ферредоксин, синтез хлорофилла                                                                         |
| Cu      | Пластоцианин, цитохромоксидаза                                                                                   |
| Mn      | Входит в ФСII, активация ферментов цикла Кребса                                                                  |
| Zn      | Синтез ауксина, карбоангидраза, алкогольдегидрогеназа                                                            |
| B       | Регулирует транспорт сахаров через мембраны, синтез клеточной стенки, прорастание пыльцы и рост пыльцевых трубок |
| Мo      | Нитратредуктаза                                                                                                  |
| Ni      | Уреаза                                                                                                           |
