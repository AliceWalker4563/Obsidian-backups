### Типы особых точек в биосистемах

Откуда взялись эти $\lambda$, см. [[15. Критерий Ляпунова|здесь]]. Про фазовые плоскости см. [[12. Кинетика биологических процессов#Математическое моделирование|здесь]].

| №   | $Re, \lambda_1$ | $Re, \lambda_2$ | $Im, \lambda_1$ | $Im, \lambda_2$ | Тип особой точки   |
| --- | --------------- | --------------- | --------------- | --------------- | ------------------ |
| 1   | < 0             | < 0             | = 0             | = 0             | Устойчивый узел    |
| 2   | > 0             | > 0             | = 0             | = 0             | Неустойчивый узел  |
| 3   | < 0             | > 0             | = 0             | = 0             | Седло              |
| 4   | < 0             | < 0             | ≠ 0             | ≠ 0             | Устойчивый фокус   |
| 5   | > 0             | > 0             | ≠ 0             | ≠ 0             | Неустойчивый фокус |
| 6   | = 0             | = 0             | ≠ 0             | ≠ 0             | Центр              |

- $Re$ (real) - действительная часть. Отвечает за устойчивость системы. Если обе < 0, то система устойчивая, если хотя бы одна > 0 - неустойчивая.
- $Im$ (imaginary) - мнимая часть. Отвечает за колебания. Если = 0, то колебаний нет, точка движется прямо или по дуге. Если ≠ 0, то точка закручивается по круг или спирали.

### Типы без вращения (Im $\lambda$ = 0)

*Устойчивый узел*. Оба числа отрицательные. Все траектории плавно стекаются в точку равновесия. 

![[Pasted image 20261120192737.png]]

*Неустойчивый узел*. Оба числа положительные. Траектории выходят из точки равновесия во все стороны. Малейший сдвиг заставляет систему безвозвратно уходить от равновесия.

![[Pasted image 20261120192913.png]]

*Седло*. У чисел разные знаки. Неустойчивая. Гиперболы.

![[Pasted image 20261120194521.png]]
### Типы с вращением (Im $\lambda$ ≠ 0)

*Устойчивый фокус*. Действительная часть отрицательная. Траектории закручиваются по спирали внутрь (затухающие колебания).

![[Pasted image 20261120193854.png]]

*Неустойчивый фокус*. Действительная часть положительная. Траектории раскручиваются по спирали наружу (раскачивающиеся колебания).

![[Pasted image 20261120193805.png]]

*Центр*. Действительная часть = 0. Замкнутые круги/овалы вокруг точки равновесия (бесконечные незатухающие колебания). Модель хищник-жертва.

![[Pasted image 20261120194137.png]]
